# Catalog Runtime Ownership

Profile and stage selection are defined in
[policy-profiles.md](policy-profiles.md); organization-source handling in
[organization-policy.md](organization-policy.md); verdicts and counts in
[report-format.md](report-format.md).

The catalog supplies applicable evidence safeguards with the runtime payload.
Source history and conflict explanations in [policy-sources.md](policy-sources.md)
are on-demand documentation, not a required additional read for every audit.

Rule-view `layer` and `stages` select core versus public destination rules and
preparation versus submission.
